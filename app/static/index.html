Как устроена приватность

Для регистрации достаточно псевдонима и пароля. Сессия хранится в HttpOnly cookie. Код восстановления показывается один раз; приложение не сохраняет его в браузере.

Если на сервере включено шифрование, данные шифруются при хранении. Это не сквозное шифрование: сервер обрабатывает записи и управляет ключом. Текущий статус виден в настройках.

ИИ для нового аккаунта выключен. При включении запрос и нужный контекст передаются провайдеру модели. Сообщения и уведомления в Telegram находятся вне зашифрованного хранилища приложения.

Время и интерфейс

Пояс синхронизируется с ботом. Старые записи сохраняют исходный пояс.

Ctrl / Cmd + K — поиск · N — новая запись · Esc — закрыть окно.

Ассистент и голос

Без ключа работает ограниченный локальный разбор. С LLM можно формулировать свободнее. API-ключ остаётся на сервере.

Микрофон требует HTTPS или localhost. В боте можно отправить обычное голосовое; перед выполнением запроса ты проверишь расшифровку.

Данные

Учебный пример: 1000 записей

Добавит 1000 учебных записей в текущий аккаунт. Это не твои личные планы. Исходные даты сохраняются; старые задачи попадут в «Просрочено». Повторный импорт не создаёт дубликатов.

Удаление можно отменить в течение 10 минут. В экспорте нет удалённых записей.
