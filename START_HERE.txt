ОРБИТА 3.2
Новая установка, Python 3.11+:
1. python3 -m venv .venv
2. .venv/bin/python -m pip install -r requirements.txt
3. .venv/bin/python -m scripts.configure
4. .venv/bin/python run.py all
5. Открой http://localhost:8000, создай аккаунт и сохрани код восстановления.

Windows: py -3 вместо python3, .venv\Scripts\python.exe вместо .venv/bin/python.
После настройки доступны start.bat, Start.command и ./start.sh.

Для телефона и ПК — один сайт в браузере. Почта не нужна.
Новая установка включает SQLCipher. AI аккаунта выключен до явного включения.
Без API работают формы, поиск и простые команды.

Есть старая база? Сначала docs/PRIVACY.md. Не меняй её ключ.
Старые web-записи не передаются первому зарегистрировавшемуся.
Храни ключ отдельно: без него базу и копии не открыть.
Шифрование действует при хранении; сервер с ключом читает записи.

Работающий сервер, копии и обслуживание: docs/DEPLOYMENT.md.
Защита и Telegram: docs/security-and-telegram.md.
Локальный адрес не является публикацией в интернете.
Не запускай бота локально с тем же токеном, что на сервере: Telegram отдаёт сообщения только одному.
В архиве нет .env, данных, ключей и пользовательских экспортов.
