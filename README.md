# Орбита 

Личный планировщик для телефона и компьютера: задачи, встречи, напоминания, поиск и команды на русском. 

**Рабочий сайт:** [https://213.171.29.94/](https://213.171.29.94/)

## Краткая история

Орбита начиналась как небольшой локальный планировщик задач и напоминаний. По мере развития в проект добавились приватные аккаунты, шифрование базы, Telegram-бот и Mini App, фокус дня, мобильная адаптация и безопасное подтверждение действий ассистента. Сейчас это единое личное пространство для планов и заметок, которое работает на телефоне, компьютере и на бесплатной ВМ Cloud.ru.

Проект развивается вокруг практичного сценария: быстро записать мысль, уточнить детали, увидеть понятный план дня и не потерять контекст в заметках. Исходный код, тесты и инструкции находятся в этом репозитории; production-версия доступна по ссылке выше.

Сайт, Telegram-бот и Mini App используют одни записи после явного подключения. Есть светлая и тёмная темы, мобильная навигация, формы, подтверждения, восстановление удаления и экспорт JSON/CSV. Сборка JavaScript не нужна.

**Фокус дня.** На главном экране можно выбрать одну задачу, главную на сегодня, и запустить на неё 25 минут без отвлечений. Выбор хранится на сервере, переживает перезагрузку и сам сбрасывается с началом нового дня в твоём часовом поясе. Кнопка «В фокус» есть у каждой активной задачи в планах.

Напоминание нельзя поставить на прошедшие дату или время — ни в форме, ни через чат, бота или API. Старые просроченные напоминания можно переименовать или отметить выполненными, но не перенести снова в прошлое.

В 3.2 добавлены видимый профиль подключённого Telegram и отключение с проверкой пароля. Старые коды, сессии Mini App и устаревшие кнопки не дают доступ после изменения привязки. Production HTTP использует ограниченный пул Waitress; попытки подбора кода учитываются между перезапусками. Настройка сервера и проверки описаны в [security-and-telegram.md](docs/security-and-telegram.md).

## Новая установка

Нужен Python 3.11+:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m scripts.configure
.venv/bin/python run.py all
```

Открой http://localhost:8000, зарегистрируйся и сохрани код восстановления. Почта и настоящее имя не нужны. Пароль — 12–128 символов, псевдоним — 3–32 латинские буквы, цифры или _. Настройка создаёт приватный ключ базы и .env без вывода секретов.

На Windows: `py -3` вместо python3 и `.venv\Scripts\python.exe` вместо .venv/bin/python. После настройки доступны start.bat, Start.command на macOS и ./start.sh.

**Уже есть данные?** Сначала прочитай [PRIVACY.md](docs/PRIVACY.md). Не меняй ключ существующей базы. Регистрация не присваивает старые общие записи первому посетителю.

## Работа с планами

Добавь запись через форму или напиши «Добавь задачу отчёт завтра». Для встречи и напоминания нужны дата и время; задача может быть без даты. В планах есть сегодня, завтра, неделя, просроченные записи, записи без даты и свой период.

Ассистент уточняет недостающие сведения и перед созданием показывает черновик: тип, название, дата, время, пояс и пересечения. «Завтра в 16», «название: Новый отчёт» и «это задача» меняют черновик; сохранение — только после «Создать». Удаление тоже требует подтверждения. Повтор HTTP-запроса с тем же ключом не создаёт вторую запись. Восстановление удаления доступно 10 минут.

## Заметки и ассистент

В заметках три вида: доски с перетаскиванием, файловое хранилище и граф связей. Редактор поддерживает Markdown, чек-листы, теги, вкладки, навигацию по файлам, ссылки \`[[Название]]\` и обратные ссылки. Недостающую связанную заметку можно создать нажатием на ссылку. Заметки прикрепляются к одному или нескольким планам; их видно в карточке плана и в редакторе. Экспорт — ZIP с Markdown-файлами по доскам, пригодный для Obsidian.

Сохранение автоматическое; при сетевой ошибке или конфликте версий редактор остаётся открытым с твоим текстом. Можно загрузить серверную версию или явно сохранить свою.

На ПК ассистент открывается кнопкой справа снизу на любой странице (Ctrl/Cmd+J). На телефоне — полноэкранная вкладка с компактным закрепом фокуса и счётчиков. Поиск находится в «Моих планах», мобильные фильтры раскрываются отдельно. Крошки без ссылок и лишние информационные блоки убраны.

Команды: «Сохрани заметку: Идеи для отпуска», «Найди заметку отпуск», «Помоги спланировать день», «Разбей задачу подготовить презентацию на шаги». Советы ИИ не создают записи автоматически. Модель получает ограниченный контекст активных планов только для запроса помощи в планировании.

## Приватность

Новая установка включает аккаунты и **SQLCipher 4**: шифруются страницы базы, история, служебные таблицы, WAL и резервные копии. Пароли хранятся как scrypt-хеши с индивидуальной солью. Сессия — случайный токен в HttpOnly cookie; в базе хранится хеш. Выход отзывает сессию. Смена и восстановление пароля отзывают старые сессии и меняют код восстановления.

Это шифрование **при хранении**: сервер с ключом читает записи. Это не сквозное шифрование и не гарантия сетевой анонимности. Приложение не требует почту, настоящее имя и трекеры. Хостинг, Telegram и AI-провайдер имеют свои правила обработки метаданных.

AI нового аккаунта выключен. Простые команды работают локально. При включении AI провайдер получает запрос и нужный контекст незавершённого действия, а не всю базу. STT настраивается отдельно; распознавание браузера тоже может использовать внешний сервис.

В настройках доступны смена пароля и удаление аккаунта с записями и диалогами. Старые копии остаются до ротации. Пользовательские JSON/CSV-экспорты содержат открытый текст. [Ключи, перенос и восстановление](docs/PRIVACY.md).

## Telegram

Добавь токен BotFather, username и разрешённые ID в секреты сервера. Без токена работает только сайт; по умолчанию бот закрыт. Публичный доступ — TELEGRAM_ALLOW_PUBLIC=1.

Отправь боту /start и /link, введи одноразовый код в настройках личного аккаунта и подтверди подключение. Telegram-записи переносятся в этот аккаунт. Код действует 10 минут; чужую уже существующую привязку использовать нельзя. Mini App проверяет подписанные initData, не наследуя cookie сайта.

Напоминания отправляются только для активных записей типа reminder с датой и временем при подключённом боте и включённой доставке. Сроки проверяются раз в 15 секунд. Сеть может задержать доставку; после сбоя возможен редкий повтор. Слишком старые новые уведомления помечаются как пропущенные. Статусы и перенос на 15/60 минут видны в интерфейсе. Встреча сама по себе уведомление не создаёт.

Если сервер не может напрямую связаться с Telegram (так у Cloud.ru), задай `TELEGRAM_PROXY=http://логин:пароль@хост:порт` — прокси используется только для Telegram.

## AI и расходы

Адаптер: https://vyceai.com/v1, основная модель claude-sonnet-4-6, резерв deepseek-v4-flash. Настройки не доказывают текущую доступность модели. При сбое работает ограниченный локальный разбор с пояснением. Таймаут — `LLM_TIMEOUT` секунд на модель (по умолчанию 16, на сервере 30), затем пауза перед повторной попыткой. STT по умолчанию выключено.

Дневные квоты: AI_DAILY_USER_LIMIT=50, AI_DAILY_LIMIT=1000, плюс ограничения частоты. Неудачная попытка тоже расходует квоту. Бесплатный сервер не делает внешний AI бесплатным; без ключа работают локальные команды и формы.

## Постоянный запуск и проверки

Сайт работает на ВМ Cloud.ru: **https://213.171.29.94/**. Как всё устроено, где лежат файлы, как делать копии и обновлять — [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). Защита и Telegram — [docs/security-and-telegram.md](docs/security-and-telegram.md).

Контейнер содержит внутренний Caddy перед Python-сервером, снаружи стоит Nginx с IP-сертификатом. Launcher управляет сайтом, ботом и копированием; сбой бота или копирования не перезапускает сайт. Копия создаётся каждые 6 часов, хранятся 28 последних; при `TELEGRAM_BACKUP_CHAT_ID` раз в сутки зашифрованная копия уходит владельцу в Telegram. Ключ базы храни отдельно.

Код для бесплатного shared-хостинга с webhook (`hosted.py`, `scheduled.py`, `setup_webhook.py`) сохранён, но сейчас не используется; старые инструкции — в [docs/archive](docs/archive).

Production требует HTTPS origin, Secure cookies, регистрацию, SQLCipher и постоянные ключи. Секреты, данные, логи и архивы исключены из Git и Docker build context. AUTH_REQUIRED=0 разрешён только как явный локальный режим общего пространства.

```sh
.venv/bin/python -m scripts.test
npm install
npx playwright install chromium
npm run test:ui
```

Браузерные тесты запускают временный сервер и запрещают внешнюю сеть. Реальная доставка, внешний AI и публичный uptime проверяются отдельно. Снимки test-results/ содержат тестовые данные и не входят в архив. Старые отчёты и заметки к релизам — в [docs/archive](docs/archive).

Пока нет повторяющихся событий, внешних календарей, browser push, совместных пространств и горизонтального масштабирования. Один запрос выполняет одно действие.
