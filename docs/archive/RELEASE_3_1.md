# Орбита 3.1 — бесплатный управляемый хостинг

Автор — Никита Ломовцев (tot-nekit). Дата проверки: 26 октября 2026.

Добавлен отдельный запуск для alwaysdata Free: website на Waitress, webhook Telegram с зашифрованной устойчивой очередью и scheduled task для напоминаний, восстановления очереди и резервных копий. Постоянные фоновые службы не нужны. Сохраняется отдельный режим VPS с Caddy и polling.

Входящие обновления защищены секретным заголовком, проверкой private chat и разрешённого владельца. Повторы не создают вторую запись, очередь ограничена, обработка одного владельца сохраняет порядок. Прерванную обработку восстанавливает расписание; устаревший worker не отправляет ответ после нового. Завершённые задания очищают исходный текст. Редкий повтор исходящей доставки при сетевой неопределённости всё ещё возможен.

Исправлен статус доставки у зарегистрированного аккаунта после подключения Telegram. Интерфейс учитывает минутный планировщик и лимит аудио 2 МБ. WSGI повторно использует существующие маршруты, проверки авторизации и изоляцию данных. Входящие частные данные не сбрасываются Waitress во временные открытые файлы. Отдельная команда prepare_hosted.py готовит новую установку без вывода и перезаписи секретов.

## Проверки

- 254 Python-теста: 253 успешны, 1 необязательный сетевой пропущен.
- Настоящий Waitress в production: SQLCipher, запрет чужого Host/Origin, Secure/HttpOnly cookie, ранний отказ для тела больше 2 МБ, запись и сессия после перезапуска, плановая зашифрованная копия.
- WSGI через валидатор и HTTP; webhook, повтор после сбоя доставки без дублирования записи, порядок владельцев, устаревший lease, удаление аккаунта, переполненная очередь и подмена proxy IP. Telegram-транспорт подменён.
- WEB, MINI, REDESIGN и AUTH: успешны, включая ширины 320–1440, светлую/тёмную темы и сценарии аккаунтов. Внешняя сеть заблокирована, Telegram SDK эмулируется.
- Секреты и пользовательские базы исключены из исходников релиза.

Новый Docker-образ этой версии ещё не собран. Предыдущая 3.0 прошла Linux CI с реальным зашифрованным перезапуском и backup; новый профиль проверен локально отдельным процессом. Локальные проверки не подтверждают публичный uptime, актуальную доступность LLM, реальную доставку Telegram или ресурсные лимиты хостинга.

## Что осталось для публикации

Владелец завершает создание аккаунта alwaysdata Free. Затем нужны загрузка, HTTPS website, расписание, проверка proxy IP, тест двух аккаунтов и реальная доставка нового напоминания. Пока сайт не опубликован. Не переноси личные данные в публичный аккаунт без отдельной проверки.

Тариф 0 €/месяц действует для личного некоммерческого проекта на alwaysdata.net. 1 ГБ диска, 256 МБ RAM; требуется вход в панель минимум раз в 120 дней. Внешний AI оплачивается отдельно, если включён. Гарантии 100% uptime нет. Точные шаги и ссылки на правила — [ALWAYSDATA.md](ALWAYSDATA.md).
