# Демонстрация Орбиты v2

## Подготовка

1. Установить Python 3.11+, зависимости и запустить `python configure.py`.
2. Для полного сценария указать свои AI/token, разрешённый Telegram ID и HTTPS PUBLIC_BASE_URL. Для сайта достаточно `python run.py all` без ключей.
3. Выполнить `python run.py doctor`, затем `python run.py all`.
4. Использовать тестовые, а не личные записи. Показ не должен раскрывать `.env`, initData, cookie или API-токены.

## Сайт: 2–3 минуты

- Показать адаптивный интерфейс и переключение темы.
- Написать «Поставь встречу с дизайнером завтра». Ассистент должен уточнить время.
- Ответить «в 15:00». Появится карточка с датой, временем и часовым поясом.
- Написать «Перенеси её на послезавтра». Проверить новую дату в планировщике.
- Открыть форму, изменить название, сохранить. Создать пересекающуюся встречу и показать подтверждение конфликта.
- Удалить запись через безопасный диалог и восстановить через Undo.
- Настройки → «Демонстрационные данные задания» → прочитать пояснение → импорт CSV с подтверждением. Повторный импорт не создаёт дубликатов. Исходные даты сохранены; старые активные записи доступны в «Просрочено», недатированные — в «Без даты».
- Найти «презентация», показать счётчик результатов и «Показать ещё». Скачать CSV/JSON.

## Telegram + Mini App: 2–3 минуты

- В настоящем боте: `/start`, `/help`, `/today`. Бот закрыт для чужих ID по умолчанию.
- Создать напоминание естественным текстом или через уточняющий диалог.
- При настроенном STT отправить voice; показать текст и подтвердить «Выполнить». Без подтверждения изменений нет.
- Открыть «Открыть планировщик»: Mini App сразу показывает планы, нижнюю навигацию и ту же запись.
- Изменить запись в Mini App; повторить `/today` в боте и убедиться в общем состоянии.
- Выполнить `/link`; на сайте в настройках ввести код. Это переключение на Telegram-аккаунт, не слияние баз.
- Включить доставку, поставить новое напоминание на несколько минут вперёд. Оставить worker работающим. Доставка проверяется с шагом 15 секунд; network/API могут задержать сообщение.
- `/export` отдаёт CSV-файл.

## Короткая проверка безопасности

- Открыть `/mini` обычным браузером: нет доступа к планам и нижней навигации, есть объяснение входа.
- Другой разрешённый Telegram ID не видит записи первого пользователя.
- Вторая вкладка с устаревшей формой получает конфликт revision вместо незаметного перезаписывания.

## Что говорить честно

Локальный режим — ограниченный parser, полноценный AI требует ключа. Telegram-интеграция и outbox реализованы кодом, но до настройки своего бота и публичного HTTPS это не развёрнутый сервис. Браузерные автотесты Mini App используют эмуляцию SDK; живой Telegram, микрофон WebView и внешние API проверяются отдельно в аккаунте владельца. Плановый срок напоминания не означает гарантированную доставку ровно в секунду.
