# Орбита 2.2

Сборка проверена 24 октября 2026 года. Эта версия завершает доработки интерфейса и повседневных сценариев; она не означает поддержку любых календарных команд или всех внешних интеграций.

## Что изменено

- Новый компактный интерфейс: спокойная светлая тема по умолчанию, полноценная тёмная тема, списки с группировкой по дням. Активные дела без даты и просроченные видны отдельными счётчиками и фильтрами. Основные экраны проверены на ширинах 320–1440 px.
- «Привет», «спасибо», вопросы о возможностях и обычные реплики не запускают поиск и не создают записи. Во время уточнения такие реплики сохраняют исходное дело. Поддержаны дополнительные естественные формы вроде «запиши», «мне нужно», «у меня завтра созвон».
- Модель может интерпретировать команду, но не придумывать разрешение на удаление или изменение. Запрос за конкретный день не превращается в поиск без фильтра даты. Неподдерживаемые действия объясняются без обещания выполнить их.
- Уточнения, подтверждение и выбор записи доступны кнопками. Они восстанавливаются после перезагрузки. Кнопки передают версию диалога: устаревшее «подтвердить» не выполнит другое, более новое действие.
- Повторная отправка блокируется на время обработки. Внутренние названия моделей перенесены из основного потока в настройки; сообщения об ошибках и ограниченном режиме остаются понятными.
- «На завтра» сохраняет время записи и рассчитывает новый день в часовом поясе самой записи. При пересечении встреч запрашивается подтверждение.
- Для связанных Telegram-напоминаний показываются состояния доставки: запланировано, в очереди, отправлено, не доставлено, пропущено. Учебные записи явно не обещают уведомлений.
- Напоминание можно перенести на 15 или 60 минут в интерфейсе и кнопками Telegram. Переносится само одиночное напоминание. Старые кнопки и повторные Telegram updates не переносят запись повторно.
- Истёкшая привязка Telegram больше не переключает сайт незаметно на другое пространство: показано объяснение и явное восстановление веб-пространства.
- Удаление из списка проверяет версию записи. Сохранены отмена удаления, поиск, экспорт, часовые пояса и защита от повторного исполнения запросов.

## Проверки

- Python: 203 теста, из них 202 PASS, один большой live-benchmark пропущен по умолчанию как отдельная opt-in проверка. Локальные тесты используют временные базы и не отправляют сообщения в настоящий Telegram.
- В исторических HTTP-тестах остаются ResourceWarning о закрытии тестовых объектов; они не скрывались и не привели к падению проверок.
- WEB, MINI и REDESIGN: браузерные сценарии PASS. Проверены создание, изменение, поиск, удаление, отмена, ошибки голоса, восстановление actions, устаревшие версии, доставка и мобильные экраны. Mini App проверен с эмуляцией Telegram SDK и настоящей локальной проверкой HMAC, а не в мобильном приложении Telegram.
- Визуально просмотрены светлая и тёмная темы на 1440×1000, мобильный планировщик на 390×844. На стабильной странице не было JavaScript pageerror.
- Отдельный прогон 22 октября с настоящим LLM API и временной базой: 9/9 сценариев, включая приветствие, напоминание, дедлайн, неделю, задачу без даты, неподдерживаемое действие, повторение, уточнение и подтверждённое удаление. Приветствие и ограничения обрабатываются программой без оплаты запроса к модели.
- Свежий прогон 24 октября: обе модели VyceAI достигали тайм-аута. Напоминание и дедлайн корректно сохранились локальным разбором; полный live-прогон остановлен, чтобы не повторять недоступные запросы. После неудачи обеих моделей приложение выдерживает паузу 60 секунд и отвечает локально. Первый такой запрос всё ещё может занять около 32 секунд, затем на время паузы нет повторного ожидания API. Восстановление внешнего провайдера не подтверждено.
- Перед обновлением сохранена согласованная резервная копия рабочей SQLite. Архив проверяется на целостность, отсутствие `.env` и секретов; запуск проверяется также из распакованной копии без локального окружения разработчика.

## Запуск

Нужен Python 3.11+. На macOS/Linux: `python3 -m pip install -r requirements.txt`, затем `python3 run.py web` или `./start.sh`. На Windows: `start.bat`. На macOS также есть `Start.command`; если система блокирует запуск скачанного файла, можно использовать команды из терминала.

Сайт открывается по `http://localhost:8000` без пароля. Для бота и LLM сначала выполните `python configure.py`: ключи вводятся скрыто и сохраняются локально. Без ключей сайт работает с ограниченным локальным разбором. Настройки модели: `docs/LLM_CONFIGURATION.md`.

В архиве находятся исходники, ресурсы, тесты и документация, но нет рабочего `.env`, пользовательской базы, логов, `.venv` и `node_modules`. После переноса на другой компьютер ключи нужно настроить заново. В архив не входят личные записи; их резервирует `python backup.py`.

Для браузерных проверок: `npm install`, `npx playwright install chromium`, затем `npm run test:ui`. Для Python-тестов: задайте пустые `OPENAI_API_KEY` и `STT_API_KEY`, затем запустите `python -m unittest discover tests`. Большой live-benchmark включается отдельно через `ORBITA_LIVE_BENCHMARK=1` и обращается к платному API.

## Границы текущей версии и дальнейшее развитие

Повторяющиеся события, уведомления заранее для обычных встреч, двусторонняя синхронизация Google/Outlook и объединение веб-записей с Telegram пока не реализованы. Поддерживаемые напоминания — одиночные записи типа «Напоминание».

Следующий приоритет — проверка получения уведомления в настоящем Telegram и личный недельный прогон. После этого: уведомление как настройка задачи/встречи, простые повторения и подтверждаемый перенос записей между пространствами. Реальная доставка на устройство не подтверждается одной проверкой heartbeat.

У VyceAI не подтверждён `/audio/transcriptions`, поэтому серверное распознавание речи выключено; браузерное распознавание доступно там, где его поддерживает браузер. Docker-сборка и публикация сервиса в этой проверке не выполнялись.
