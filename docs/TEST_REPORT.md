# Отчёт проверки Орбиты v2.0

Актуальный отчёт версии 2.2 от 24 октября 2026 года: [RELEASE_2_2.md](RELEASE_2_2.md). Ниже сохранены исторические результаты.

## Дополнение: UI общего веб-пространства

Актуальные `tests/e2e.mjs` и `tests/e2e-mini.mjs` самостоятельно запускают `tests/e2e-server.mjs`: временная SQLite, свободный loopback-порт, тестовые ID/токен, запрет чтения `.env` и внешних соединений. Рабочий localhost:8000 не используется. Playwright timeout — 15 секунд. Дата создания в Mini вычисляется в Europe/Moscow, а не через UTC-день.

Веб-регрессии дополнены выборками «Без даты»/«Просрочено» с исключением выполненных записей, переносом недатированной задачи на сегодня, завершением просроченной, счётчиками API, раскрытием демоимпорта и отсутствием отвязки у несвязанного сайта. Подмена API проверяет настроенную LLM, фактический LLM-ответ, резервный локальный ответ, запрет записи при `stt=false`, отказ доступа к микрофону и ошибку STT с освобождением микрофона. Mini проверяет отсутствие веб-кнопки отвязки. Исторические результаты ниже относятся к прежней версии; итог новых сценариев следует сверять по текущему запуску после интеграции.

## Итог

- **138 Python unit/integration тестов — PASS.** Команда: `python -m unittest discover -s tests -v`.
- **Два браузерных сценария — PASS:** сайт и Mini App в локальном Chromium/Playwright.
- Python compileall и синтаксические проверки JavaScript — PASS.
- `python run.py doctor` — PASS: версия Python, CSV, часовые пояса, запись в data.
- Визуально просмотрены 15 состояний сайта/Mini App, включая светлую/тёмную тему, мобильный экран 390×844, формы и подтверждение удаления. Финальные PNG лежат в screenshots/.

Полный вывод Python-тестов — test-output.txt. UI-тесты находятся в tests/e2e.mjs и tests/e2e-mini.mjs. Проверка выполнена локально на Linux, Python 3.13 и Chromium; Windows/macOS, Firefox/Safari и реальные мобильные устройства отдельно не проверялись.

## Сайт: браузерный сценарий

Создание через чат, форма редактирования, поиск, собственный диалог удаления, Undo, обязательные поля, четыре мобильных раздела, тёмная тема. Проверено отсутствие горизонтального переполнения и JS pageerror в сценарии. На 390×844 composer располагается выше нижней навигации.

## Mini App: браузерный сценарий

Эмулируется Telegram WebApp SDK. InitData подписывается тестовым секретом и проверяется настоящим локальным сервером. Проверены закрытый анонимный экран без навигации, вход, создание, чтение той же записи через API того же Telegram ID, отсутствие записи у другого ID, четыре раздела, удаление и расположение composer. Использованы вымышленные тестовые ID 101/202 и нерабочий тестовый bot token.

Это **не тест в настоящем Telegram**. SDK events, системные permissions и WebView могут отличаться от эмуляции.

## Что исправлено при QA

- Поле ввода и нижняя навигация на мобильном экране больше не перекрывают друг друга в проверенном viewport.
- Закрытый Mini App не показывает нижнюю навигацию приложения.
- Иконки не зависят от отсутствующих glyph шрифта; исправлено расположение декоративной орбиты.
- Разделены кнопки восстановления и выхода; улучшены контраст полей и destructive confirmation.
- Повторное включение уведомлений и перенос срока обратно восстанавливают cancelled outbox, но не дублируют sent.

## Не проверено здесь / условия запуска

- Реальный Telegram Bot API, BotFather, long polling с рабочим токеном и доставка в личный чат.
- Mini App внутри Telegram iOS/Android/Desktop, SDK haptics/back button и разрешения микрофона.
- Реальные OpenAI-compatible LLM/STT, качество модели, стоимость, лимиты и доступность аккаунта. AI/STT-ветки в тестах используют подмену провайдера.
- Браузерный микрофон/распознавание/озвучивание на устройствах пользователя.
- Сборка Docker, развёртывание Render, HTTPS-сертификат и публичный домен.
- Внешний security audit, нагрузочный тест, многорепличная эксплуатация и длительная проверка восстановления после аварий.

Для live-приёмки нужны свои токен/AI-ключ, allowlist, HTTPS, постоянный диск и always-on worker. Запустить сценарий из DEMO.md. Архив — готовый исходный проект с локальными проверками, не опубликованный сервис с уже подключёнными аккаунтами.
