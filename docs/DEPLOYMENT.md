# Публикация 3.0

Нужен один постоянно работающий сервер с диском, Docker Compose и HTTPS proxy. Основной вариант без новой подписки — существующий сервер владельца. Перед установкой проверь ресурсы, порты и текущие сервисы; их конфигурации не заменяются целиком.

## Бесплатное размещение

Если сервера нет, возможен Oracle Always Free: только ресурсы с отметкой Always Free в домашнем регионе, в пределах актуальной квоты. При проверке документация указывает до 2 OCPU/12 ГБ A1 суммарно и 200 ГБ block storage. Условия перепроверяются в аккаунте. Для регистрации обычно нужны телефон и карта; переход на платный аккаунт не нужен.

Нехватка ёмкости и отзыв простаивающей VM возможны. Не создавай искусственную нагрузку ради обхода правил. Сервисы с засыпанием, эфемерным диском, пробными кредитами и временные туннели не считаются постоянным бесплатным размещением этого приложения.

## Подготовка

Клонируй приватный репозиторий через SSH deploy key с правом чтения. GitHub-токен не попадает в исходники и Compose. Сохрани .env с правами 0600:

```dotenv
PUBLIC_BASE_URL=https://your-domain.example
DATABASE_KEY=<32 случайных байта в base64url>
APP_SESSION_SECRET=<отдельная случайная строка длиной 32+>
```

Ключ создаётся `python manage.py keygen --output /safe/orbita.key`; перенеси значение напрямую в секреты сервера без чата и коммитов, сохрани отдельную защищённую копию. Не генерируй новый ключ при перезапуске.

AI/Telegram необязательны. Ключи задаются только в секретах сервера. Внешний AI может тарифицироваться независимо от бесплатного VPS.

Добавь HTTPS vhost в существующий Caddy/nginx, сохранив Host:

```caddy
your-domain.example {
    reverse_proxy 127.0.0.1:8000
}
```

DNS должен указывать на сервер, 80/443 доступны для сертификата. Без своего домена можно использовать имя sslip.io, соответствующее IP; доступность и сертификат проверяются отдельно. Python-порт не открывается наружу.

## Запуск и приёмка

```sh
docker compose up --build -d
docker compose ps
curl -fsS https://your-domain.example/api/health
```

Compose включает production, регистрацию, SQLCipher, Secure cookies, постоянный том и restart: unless-stopped. Внутренний Caddy слушает только 127.0.0.1:8000; HTTPS завершает внешний proxy. Включи автозапуск Docker после перезагрузки. Команда docker compose down -v удаляет данные и не используется для обновления.

Проверь HTTPS без отключения проверки сертификата; Secure/HttpOnly cookie; изоляцию двух аккаунтов во всех списках, изменениях и экспорте; сохранность после перезапуска; восстановление копии с правильным ключом на отдельном пути; мобильные и настольные сценарии. Реальная доставка Telegram проверяется отдельно от подмены SDK.

Внешний монитор проверяет /api/health и сообщает владельцу о сбое. Один сервер может прерваться при проблемах диска, сети или провайдера; перезапуск и копии не означают 100% uptime.
