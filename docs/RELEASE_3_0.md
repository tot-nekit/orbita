# Орбита 3.0 — проверка 26 октября 2026

Переход от общего локального пространства к отдельным аккаунтам для публикации. Создатель проекта — Никита Ломовцев (tot-nekit). Код подготовлен для приватного репозитория владельца; секреты и пользовательские данные исключены.

## Что изменилось

- Регистрация без обязательной почты, восстановление по одноразовому коду, смена пароля и удаление аккаунта.
- scrypt-хеши паролей, случайные отзывные сессии в HttpOnly cookie, изоляция запросов по владельцу и защита от применения действия после удаления аккаунта.
- SQLCipher 4 для базы, WAL и проверенных копий. Режим production не допускает открытия без шифрования, публичного общего аккаунта или незащищённых cookie.
- Отдельные страницы входа и восстановления в общей визуальной системе; очистка приватного DOM и незавершённых запросов при выходе и переключении между вкладками.
- AI новых аккаунтов выключен до явного включения. Дневные квоты и локальный режим ограничивают расходы при сбое провайдера.
- Привязка своего Telegram переносит его записи в личный аккаунт; чужая существующая привязка не перехватывается.
- Supervisor корректно останавливает процессы по SIGTERM, проверяет HTTP и завершает службу для перезапуска при сбое. Caddy ограничивает подключения и время запросов.
- Автоматические зашифрованные копии, проверка повторного открытия, ротация и отдельная процедура переноса старой базы.

## Проверено локально

240 Python-тестов: **239 успешны, 1 необязательный сетевой тест пропущен**. Включают реальные зашифрованные файлы, WAL, неверный ключ, миграцию, backup/recovery, конкурентное восстановление аккаунта и запуск production через Caddy с сохранностью данных после перезапуска.

Четыре браузерных набора успешны: WEB, MINI, REDESIGN, AUTH. Проверены формы, изоляция, подтверждения, удаление/undo, жизненный цикл аккаунта, выход в соседней вкладке, светлая/тёмная темы и ширины 320/390/768/1440. Telegram SDK и внешняя сеть подменены или заблокированы. Реальные телефоны и доставка Telegram этим не проверены.

Локальная база перенесена в SQLCipher. Записи, аккаунты, история, диалоги и служебные квитанции сверены с прежним состоянием; проверенная зашифрованная копия создана до удаления устаревшего plaintext-файла. Ключ находится вне папки проекта, не в Git. Старые web-записи не присваиваются первому зарегистрировавшемуся.

## Внешние ограничения

Обе настроенные модели VyceAI при синтетической проверке не ответили за 10 секунд каждая. Текущая доступность LLM не подтверждена; нельзя выдавать прежние успешные прогоны за текущую проверку. Локальные команды и формы продолжают работать. STT по умолчанию выключено.

Публичный HTTPS-сайт и постоянный бесплатный хостинг пока не подтверждены. Настройка платного Render удалена по выбору владельца. Для размещения нужен доступный существующий сервер или аккаунт подходящего Always Free VPS. Одна известная SSH-конечная точка не ответила при проверке соединения; её конфигурация не менялась.

Шифрование при хранении не является E2EE. Абсолютная анонимность, внешний независимый security audit и 100% uptime не заявляются. Скопированные пользователем экспорты и сообщения внешних сервисов лежат вне контроля приложения.
